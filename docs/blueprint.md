# **App Name**: Carte Blanche Showcase

## Core Features:

- Photo Upload & Carousel: Allow users to upload image files and display them in a continuously animating, smooth photo carousel.
- Card Upload & Display: Enable users to upload 'cards' which include a PDF document and a distinct cover image, presented within their own animating carousel.
- Card Deletion: Provide a button to effortlessly delete individual uploaded 'cards' from the display in case of error.
- Scrolling Animations: Implement smooth, scroll-triggered visual animations across the single-page application, enhancing the overall user experience.
- Interactive Card Preview Tool: When hovering over a card, activate a 'casino-style' visual tool that dynamically generates and displays key highlights or a visual summary from the associated PDF content.

## Style Guidelines:

- Primary color: Elegant Mauve (#C1839F). This desaturated, soft pink-purple evokes romance and timeless elegance, aligning with the 'Luxury Editorial Wedding' mood.
- Background color: Ethereal Whisper (#FCF7FA). A very light, almost-white shade with a subtle hint of the primary's hue, providing an airy, sophisticated, and clean canvas for content.
- Accent color: Soft Lavender (#D6A9C8). This muted light lavender, an analogous hue to the primary, offers gentle visual contrast and depth without overwhelming the elegant aesthetic.
- Headlines will utilize 'Playfair', a sophisticated serif font for an elegant and high-end feel, as specified.
- Body text, subtitles, and vertical labels will use 'PT Sans', a humanist sans-serif for its clear readability and modern warmth, pairing harmoniously with the headline serif.
- Utilize delicate line-art icons that mirror the requested botanical and pencil-sketch illustration style, integrating seamlessly into the elegant design.
- The layout will follow an asymmetric, editorial pattern, emphasizing generous whitespace, and incorporating subtle overlapping elements like cards or image overlays, with section margins of 80-120px.
- Integrate smooth, subtle animations for all carousel movements, scroll-triggered element transitions, and engaging hover effects like the interactive card preview, ensuring a refined and responsive user experience.
